# CODI-UNCA — Entregables del Hackathon Oaxaca 2027

Repositorio de **entregables** de CODI-UNCA: documentos, presentación, video y evidencias.
**No contiene código fuente** de la aplicación.

- Aplicación desplegada: https://code-unna.vercel.app/
- Código fuente y dependencias: https://github.com/lierikgomez-pixel/Code-UNCA

## Estructura

```text
README.md
presentacion.pdf
Video-de-demostracion.mp4
01-definicion_proyecto/   → alcance, instrucciones, declaración de IA y ficha
02-modelos_IA/            → paquete de entrenamiento, evidencias y arquitectura
03-interfaz/              → perfiles, HCI, documentación y flujo de interacción
04-propuesta_negocio/     → propuesta.md y propuesta.pdf
```
