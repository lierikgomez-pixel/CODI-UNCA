# 01 · Definición del proyecto

Este repositorio contiene **solo entregables**, no código fuente.

| Archivo | Contenido |
| --- | --- |
| `reporte_detallado.pdf` | Contexto, decisiones técnicas, GPU, incidencias y verificación del despliegue. |
| `reporte_detallado.md` | Versión editable del reporte. |
| `guion_defensa.md` | Guion literal de 15 minutos: 2 min problema/usuario/solución, 4 min demo, 4 min entrenamiento/evaluación/diseño y 5 min preguntas. |
| `instrucciones.pdf` | Guía de instalación y uso en formato PDF. |
| `instrucciones.md` | Versión editable de las instrucciones. |
| `declaracion_ia.pdf` | Declaración de uso de IA, funciones simuladas y TRL 5. |
| `declaracion_ia.md` | Versión editable de la declaración. |
| `ficha_tecnica.pdf` | Ficha técnica de 3 páginas (máximo 4 permitidas). |
| `guion_video.md` | Narración del video de demostración. |
| `indice_entregables.md` | Mapa requerimiento → entregable. |

La presentación y el video están en la raíz: `presentacion.pdf` y `Video-de-demostracion.mp4`.
